# Task4.2DCloudFunction

This project combines an Arduino-based 2D control system with a web interface.

## Structure

- `Arduino/Task4_2D.ino` - Arduino sketch
- `Web/index.html` - main web page
- `Web/style.css` - page styling
- `Web/script.js` - frontend logic

## Run

1. Open the Arduino sketch in the Arduino IDE and upload it to your board.
2. Open the `Web` folder in a browser, or serve it locally.
3. Verify the embedded device and web interface are communicating as expected.
