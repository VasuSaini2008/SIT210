
# SIT210 Task 5.2C – Change Light Intensity Using GUI

## Description

This project extends Task 5.1P by adding a brightness slider to the GUI.  
The slider controls the intensity of the living room LED using PWM.

## Hardware

- Raspberry Pi
- 3 LEDs
- Resistors
- Breadboard
- Jumper wires

## Rooms

- Living Room
- Bathroom
- Closet

## How It Works

The GUI allows the user to select a room using radio buttons.

The living room LED uses PWM to control its brightness.  
The brightness slider can change the LED intensity from 0% to 100%.

## Software

- Python
- Tkinter
- RPi.GPIO
